Aplikacija Text-me pruza razlicite funkcionalnosti za razlicite vrste korisnika.Postoje tri razlicite vrste korsnika i to obican user, premium user i admin. U zavisnosti od uloge korisnik moze imati sldece funkcionalnosti:

Obican user: 

1.Mogucnost da salje tekstualne poruke ostalim korisnicima kao i mogucnost da salje poruke u grupe u koje je ubacen

2.Slanje brze poruke u vidu srca kao i mogucnost slanja gifova

3.Moze da pristupa svom profilu gde moze da: edituje informacije o sebi, promeni svoju lozinku, kao i da obrise svoj nalog

Premium user

Premium user ima sve funkcionalnosti kao i Obican user i ove dodatne:

1.Mogucnost da brise poruke koje je on poslao

2.Mogucnost da posalje razlicite vrtse fajlova

3.Mogucnost za slanje slika

4.Mogucnost za slanje glasovnih poruka

5.Mogucnost slanja emotikona

6.Mogusnost za kreiranje novih grupa

Admin user:

Admin user ima sve funkcionalnosti premium usera i jos par dodatnih

1.Mogucnost da menja uloge korisnika(Moze mu dati admin privilegije)

2.Mogucnost da blokira korisnike(Blokirani korisnik ne moze koristiti aplikaciju dok ga neki od admina ne odblokira)
